Q_Salons PNG Brand Assets

This pack contains the full brand identity concept board and cropped PNG previews:
- Primary dark-background logo
- Light-background logo
- App icon and favicon preview
- Horizontal, icon-only, monochrome, banner, and compact logo variations
- Brand color/service icon panel
- Tagline graphic

Important:
These are cropped PNG previews from the generated concept board, so some files may include
panel backgrounds or labels. They are not transparent, production-ready vector exports.
For the cleanest website implementation, use the primary/light logo crops as visual references
and have the logo redrawn as SVG (or recreate it with an editable vector tool) before final launch.
Brand palette intended by the concept:
Midnight Blue #081B38, Gold #DAAF37, Ivory #F5F3EE, Charcoal #1A1A1A, Booking Green #16A34A.
